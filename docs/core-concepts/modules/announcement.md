# Announcement

The **Announcement** module allows administrators to publish news, maintenance notices, and updates directly to the Client Area.

## Features

- **Rich Text Editor**: Write detailed announcements using formatting.
- **Client Area Integration**: Announcements are displayed prominently on the Client Area dashboard and have their own dedicated news page.
- **Drafts and Publishing**: Save announcements as drafts before making them live.

## Configuration

1. Navigate to **Admin Area** > **Plugins** > **Modules**.
2. Ensure the **Announcement** module is **Installed** and **Enabled**.
3. Once enabled, a new **Announcements** menu item will appear in your Admin Area sidebar.

You can use the new menu to create, edit, and manage all your announcements.
