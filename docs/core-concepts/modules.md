# Modules

**Module Plugins** (Add-ons) extend the core functionality of Billmora. Unlike Provisionings, Gateways, or Registrars (which have specific lifecycles), Modules are flexible and can do almost anything.


## Built-in Modules

Billmora comes with a few built-in modules to help you get started:
- [Affiliate](/docs/core-concepts/modules/affiliate): Set up a referral program for your clients.
- [Announcement](/docs/core-concepts/modules/announcement): Publish news and updates to the Client Area.

## Managing Modules

To manage add-on modules:
1. Navigate to **Admin Area** > **Plugins** > **Modules**.
2. You can install, configure, or disable modules from this page.
3. Some modules may inject new pages into the Admin Area sidebar or the Client Area navigation.
